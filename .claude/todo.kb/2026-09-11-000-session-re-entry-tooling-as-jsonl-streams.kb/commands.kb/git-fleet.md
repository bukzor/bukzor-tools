# git-fleet

`git-fleet log --since T` and `git-fleet status --dirty`: [selection] for
repo roots, [git-fleet-emission], and a view that groups by repo. Nothing
claude-specific; it is the cross-repo `git log` the owner has wanted
whenever work spans more than one checkout.
