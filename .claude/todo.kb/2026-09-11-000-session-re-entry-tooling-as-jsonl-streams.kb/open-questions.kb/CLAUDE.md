# Open questions

Decisions the design leaves to the owner, one per file, with the
candidates considered and the agent's recommendation marked as such.

## What belongs here

A question with at least two live candidates whose answer changes what
gets built. State the candidates as short bullets; a candidate needing a
paragraph gets its own file under a `$QUESTION.kb/`.

## What does not belong

Questions a measurement would settle; run the measurement and file it in
`../discovered-constraints.kb/`. Questions already ruled; when the owner
rules, rewrite the file to state the ruling and why, and keep it.

## When to add

When a stage or command file would otherwise have to pick between
alternatives the owner has not seen.
